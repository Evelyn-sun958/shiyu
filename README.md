# 时语 · 语音时间轴 ✨

长按说话，AI 自动生成时间轴。记录每一天，看见你的时间。

## 在线地址

**https://evelyn-sun958.github.io/shiyu/**

（大陆访问 github.io 偶尔会时快时慢；如果彻底打不开，等几分钟再试或换个网络。若长期不稳定，可升级为腾讯云 COS 国内直连方案。）

## 使用方法

1. **打开链接**（手机浏览器推荐 Safari / Chrome）
2. **长按底部 🎙️ 说话**，松开后自动解析出时间块（时间段 + 事件标题 + 分类 + 感想）
3. AI 解析需要**你自己的 DeepSeek API Key**：
   - 到 [platform.deepseek.com](https://platform.deepseek.com) 注册并充值（充几块钱可以用很久）
   - 点右上角 ⚙️ 设置，粘贴你的 Key 保存
4. 支持日视图 / 周视图、按日期跳转、日复盘与周复盘（AI 双板块：时间管理 + 情绪碎碎念）

## 强烈建议：添加到主屏幕（类 App 体验）

- **iPhone**：Safari 打开 → 底部分享按钮 ⬆️ →「添加到主屏幕」
- **安卓**：Chrome 打开 → 右上菜单 ⋮ →「添加到主屏幕 / 安装应用」

添加后：独立图标、全屏运行、可离线打开，数据保存在独立的存储空间，**不受浏览器清理影响更小、更安全**。

## ⚠️ 数据安全必读

- 你的所有记录、API Key **只保存在你自己设备的浏览器本地**，不上传任何服务器——彻底私密，但也意味着：
  - **清除浏览器数据 / 卸载浏览器 = 数据清零**
  - iPhone 用 Safari 网页版若 **7 天不打开**，系统可能自动清空数据（添加到主屏幕后不受此限制）
- **防丢措施**：⚙️ 设置 →「备份与恢复」→ **导出备份**（JSON 文件，建议存微信收藏或网盘）。每周一次，超 7 天未备份应用会自动提醒。换手机或误删后用「导入恢复」一键还原。

## 隐私说明

- 数据与 Key 全部本地存储（localStorage）
- 仅在 AI 解析 / 复盘时把你的一段语音文字发给 **你自己填写的** DeepSeek 接口

## 技术说明

纯静态单文件应用（index.html），无后端、无数据库、无追踪。部署于 GitHub Pages（国际线路）与 腾讯 EdgeOne Pages（国内直连线路），任选一个打开，数据互不相通（同一条链接的数据延续）。

## 本地开发

直接用任意静态服务器打开 `index.html` 即可，或：

```bash
npx serve .
```
